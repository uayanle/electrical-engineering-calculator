
## Electrical Engineering Calculator

Python • Tkinter • Electrical Engineering

Hi, this is a desktop application built using Python and Tkinter. This project provides a collection of electrical engineering calculators commonly used by students and engineers.

This was developed to help strengthen my Python programming skills while applying core electrical engineering principles learned during my degree.

## Calculator Features

- Three Phase Power Calculator
- Voltage Drop Calculator
- Transformer Calculator
- Power Factor Calculator
- Motor Current Calculator
- Cable Size Recommendation
- Short Circuit Current Calculator

## Calculations Included

### Three Phase Power
Calculates three-phase electrical power using voltage, current and power factor.

### Voltage Drop
Calculates voltage drop across a cable.

### Transformer
Calculates transformer secondary voltage using the turns ratio.

### Power Factor
Calculates power factor from real and apparent power.

### Motor Current
Calculates three-phase motor current from power, voltage, power factor and efficiency.

### Cable Size Recommendation
Recommends a cable size based on the calculated current.

### Short Circuit Current
Calculates fault current using Ohm's Law:

I = V / Z
